# 操作系统复习笔记

## 快表

TLB（Translation Lookaside Buffer，快表）是 MMU 内部的页表项缓存。CPU 发出虚拟地址后先查 TLB：命中就直接得到物理页框号，未命中才进行页表遍历。TLB 不是 Page Table 本身，也不是缺页异常。TLB 命中不会触发内核介入。

## 缺页异常

Page Fault 发生在页表项有效位表示该页不在物理内存时。内核缺页处理程序把页面从磁盘换入，然后重新执行导致异常的那条指令。如果虚拟地址非法，内核会向进程发送段错误信号，而不是继续换页。

## 多级页表

现代操作系统常使用多级页表。一次 TLB 未命中可能触发多次内存访问，每一级页表都要读取一个页表项。页表遍历是硬件与操作系统共同参与的地址翻译过程，不等同于缺页异常。
