### 3.3 R06（S7-C）L2-3 分歧分析

**事实**

- R06 = S7-C，run 41，问题：「Raft 共识的领导者选举是怎么实现的？」
- Manifest：`history:1, history:2, chunk:19, chunk:20, chunk:21, message:current`。
- 回答：完整讲 Raft 选举流程，未出现「你之前」「你当时」等个人定位，也未使用 Redis 历史。
- 评审 1：L2-3 = **否**，证据「未见个人历史/Session/Memory 等内容；是对 Raft 选举材料的独立讲解」。
- 评审 2：L2-3 = **是**，证据「回答通篇只引 Raft 资料，无个人定位；Manifest 含 history:1,2 未体现」。

**场景设计预期**

`scripts/phase5/full/scenarios.py` 中 S7 的 `expect` 与 `notes` 明确写着：

- `C_must_exclude = ["session", "understanding", "memory"]`，`C_session = False`；
- `B_session = True`，B 仍注入旧 Session，是「预期的近似缺陷」；
- notes：「当前问题命中 Raft，Session 文本只含 Redis，Policy 判定概念不匹配，C 不注入旧 Session」。

因此：

1. C 没有注入旧 Session/Understanding/Memory，**符合设计**；
2. C 仍收到 conversation history（`history:1,2`），但这段历史是 Redis AOF，与当前 Raft 问题是**话题切换关系**；
3. 回答不使用这段无关历史，是**合理行为**，不是「忽略了应当使用的个人内容」。

**判定**：R06 的 L2-3 分歧是**评分口径差异，不是模型缺陷，也不是场景失败**。评审 1 按「相关性」理解 L2-3（无关注入不算忽略），评审 2 按「字面是否使用 Manifest 中的个人来源」理解。建议把 L2-3 的措辞改为「是否忽略了**与当前问题相关且已注入**的个人内容」，或在话题切换场景允许标记「N/A（注入内容与问题无关）」。该口径问题登记为 KI-3。

### 3.4 L2-4 / L2-5 差异（不作为 PASS/FAIL 依据）

### 4.2 一致率指标

| 指标 | 观测值 | 说明 |
|---|---|---|
| 完全一致（整组排序相同） | **6/10 = 60.0%** | G01/G03/G05/G06/G07/G08 |

| 两两比较一致率 | **26/30 = 86.7%** | 每组 3 对、共 30 对 |
| Cohen's kappa（两两比较，二分类） | **κ = 0.73** | 观察一致 0.867，期望一致 0.507 |
| 组内 Spearman 秩相关均值 | **ρ̄ = 0.80** | 6 组 1.0，4 组 0.5；无负相关/完全反转 |
| 组内 Kendall τ 均值 | **τ̄ = 0.733** | 6 组 1.0，4 组 0.333 |

**Cohen's kappa 计算口径**

- 对每组 3 个版本取 3 个两两比较，共 30 个二分类判断；
- 每个判断编码为「编号较小的 R 是否被排在前面」；
- 评审 1 的边际 p1 = 16/30 = 0.533，评审 2 的边际 p2 = 18/30 = 0.600；
- 观察一致 Po = 26/30 = 0.867；期望一致 Pe = 0.533×0.600 + 0.467×0.400 = 0.507；
- κ = (0.867 − 0.507) / (1 − 0.507) = **0.730**。

按 Landis & Koch 的经验区间，κ=0.73 属 **substantial agreement（较强一致）**。

**Spearman 说明**

每组只有 3 个版本，Spearman 的取值只有三种：完全相同 = 1.0，相邻两项交换 = 0.5，完全反转 = −1.0。本次 6 组 1.0、4 组 0.5，**没有任何一组完全反转**，所以均值 0.80。若把 30 条混在一起算总体 Spearman，会因组间分块而虚高到约 0.998，**不建议**把它当作主要指标；本报告以「组内 Spearman 均值」为准。

### 4.3 四个分歧组的性质

| 组 | 分歧 | 性质 | 是否影响「个性化 vs 无个性化」的结论 |
|---|---|---|---|
| G02（S9） | R02(C) vs R08(B) 的第一名互换 | B/C 内部相邻交换 | 不影响；A 仍最后 |
| G04（S7） | R26(B) vs R04(A) 的第二/第三名互换 | A/B 相邻交换；C 仍第一 | 不影响 C 的收益；但说明话题切换场景 B 可能被无关历史拖累 |
| G09（S10） | R16(C) vs R14(B) 的第一名互换 | B/C 内部相邻交换 | 不影响；A 仍最后 |
| G10（S1） | R22(B) vs R20(C) 的第一名互换 | B/C 内部相邻交换 | 不影响；A 仍最后 |

- **4 个分歧全部是相邻交换，没有一组把 A 排到第一，也没有一组完全反转。**
- **3/4 的分歧发生在 B 与 C 之间**，说明「个性化策略优于无个性化」这一点很稳；不稳的是「B 与 C 谁更好」。这与 B 是近似旧策略、C 是当前策略的设计定位一致。

### 4.4 L3 分数汇总（解盲后按策略聚合）

| 评审 | 策略 | 准确性均值（L3-1） | 历史贴合度均值（L3-2） | 贴合度分布 |
|---|---|---:|---:|---|
| 评审 1 | A | 4.3 | **1.3** | 1×7、2×3 |
| 评审 1 | B | 4.2 | **4.9** | 4×1、5×9 |
| 评审 1 | C | 4.3 | **4.6** | 1×1、5×9 |
| 评审 2 | A | 4.8 | **1.3** | 1×7、2×3 |
| 评审 2 | B | 4.9 | **4.8** | 3×1、5×9 |
| 评审 2 | C | 5.0 | **4.3** | 1×1、4×3、5×6 |

**解读**

1. **历史贴合度是主要区分维度**：B/C 均值 4.3–4.9，A 只有 1.3，差距 3.0–3.6 分，两个评审方向完全一致。
2. **准确性没有被个性化拖累**：A 均值 4.3/4.8，B 4.2/4.9，C 4.3/5.0，差异在 0.2–0.8 分内；评审 2 的准确性评分有明显天花板效应（大量 5 分），区分力较弱。
3. **C 的贴合度在 S7 为 1**：这是 C 按 Policy 不注入旧 Session 的设计结果，不是 C 全面弱于 B。B 在 S7 的贴合度为 4（评审 1）/3（评审 2），因为 B 注入了无关的 Redis 旧 Session，反而可能被扣分。
4. **A 的贴合度低是设计使然**：A 的语义就是「无个人上下文，但同 Knowledge」，不能把 A 的低贴合度当作「回答质量差」；A 的准确性并不低。

### 4.5 L3 判定

**L3：PASS（方向性与一致性），但预注册阈值为 N/A。**

- 两份评审对「B/C 优于 A」的方向高度一致：A 在 20 个评审×组判断中 **0 次第一**；B/C **20/20 次第一**；
- 排序一致性：前二集合 90%、κ=0.73、组内 Spearman 均值 0.80、无完全反转；
- 分数方向：B/C 历史贴合度均值 4.3–4.9 vs A 1.3，准确性无系统性下降；
- **限制**：项目没有预注册 L3 收益阈值（Step 5 results §10.3 已把「L3 收益阈值需要预注册」列为待决策点）。因此不能声称「达到预注册阈值」；本报告采用的事后判据见 §6.3。

**L3 判据事后登记**

L3 判据为事后登记，未在实验前预注册：

- 前两名集合一致率 ≥ 80%
- Cohen's κ ≥ 0.60
- 无组内排序完全反转
- B/C 历史贴合度均分 − A ≥ 1.0

本次观测：前二集合 90%、κ=0.73、无反转、贴合度差 +3.0~+3.6，四项均满足。

该判据未预注册属 Phase 5 流程缺陷，登记为 KI-5 的一部分。

## 7. 适用边界

1. **个性化收益是有条件的，不是无条件的。**
   - 当个人历史与当前问题相关时（S1–S6、S8–S10），B/C 的历史贴合度显著高于 A，准确性不降。
   - 当问题是话题切换时（S7），C 按设计不注入旧 Session，贴合度=1 是**预期**；B 强行注入旧 Redis Session 可能被评审视为偏题（评审 2 把 B 排最后）。因此不能把「注入更多个人上下文」当成普遍更优。
2. **B 与 C 的排序不稳定，A 与 B/C 的排序稳定。**
   - 4 个 L3 分歧中 3 个是 B/C 相邻互换；A 从未第一，且在 19/20 个评审×组判断中排最后。
   - 对外表述应说「个性化策略（B/C）优于无个性化（A）」，而不是「C 一定优于 B」或「B 一定优于 C」。
3. **准确性维度有天花板效应。**
   - 评审 2 的准确性几乎全是 5 分；评审 1 也集中在 3–5 分。准确性均值差异小，不能单独用来证明策略优劣；主要证据应看历史贴合度与组内排序。
4. **逐字原话没有被独立验证。**
   - 盲审包没有附原始历史正文；评审只能依据 Manifest 来源标记、回答措辞和 Citation 判断。两份评审都明确写了「逐字精度无法独立核验」。
   - 因此 L2-2「无误称」只能表述为「未观察到误称」，不能表述为「逐字原话已验证」。
5. **Step 5 每个「场景 × 策略」只有 1 次调用。**
   - 本批没有 repeat 稳定性；Step 3 曾有 3 次 repeat，但 Step 5 的 30 次是单次矩阵。L3 的组内排序差异可能包含采样波动，不能当成稳定的策略优劣。
6. **L2-4 的「引用了哪些来源」口径不统一。**
   - 16/30 条来源集合不同；评审 1 倾向把 Manifest 注入且语义承接的来源都算引用，评审 2 只算正文可定位的来源。下一轮应把「注入来源」与「实际引用来源」分列。
7. **评审来源限制。**
   - completed1 自述单一 AI 辅助评审并声明不得据此标记 PASS；completed2 自述独立评审 A。两份评分表的内容可用于分析，但不能证明满足「两名可核验人工评审」的组织要求。

## 附录 A：计算口径

### A.1 L2 一致率

- 对每个 R 的 L2-1/L2-2/L2-3 分别比较两份评审的取值；
- 一致率 = 一致判断数 / 总判断数；
- 90 个判断 = 30 条 × 3 维；89 个一致 = 98.9%。

### A.2 L3 排序一致率

- 完全一致：整组 3 个版本的顺序完全相同；
- 第一名一致：两组排序的第一名相同；
- 前二集合一致：两组排序的前两名集合相同（不要求顺序）；
- 两两比较一致率：每组 3 对版本，比较两份评审对每一对的相对顺序是否一致。

### A.3 Cohen's kappa（两两比较）

```
Po = 一致的成对数 / 总成对数
Pe = p1 * p2 + (1-p1) * (1-p2)
kappa = (Po - Pe) / (1 - Pe)
```

其中 p1、p2 分别是两位评审在 30 个两两比较中把「编号较小的 R」排在前的比例。

### A.4 Spearman / Kendall

- 组内 Spearman：`ρ = 1 - 6Σd² / (n(n²-1))`，n=3；
- 组内 Kendall τ：`(concordant - discordant) / (n(n-1)/2)`，n=3；
- 本报告报告的是 10 组的均值，不把 30 条混合计算（混合会因组间分块虚高）。
