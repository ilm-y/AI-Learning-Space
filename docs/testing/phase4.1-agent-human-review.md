建议流程：先只用本表独立评分；全部填写后再与自动校验结果对照，并单独记录一致/不一致。**在人工分数填写前，不计算 Judge–human 一致率、Kappa 或「Judge 已校准」。**

## 填写说明

- 分数：`0` 不满足、`1` 部分满足、`2` 满足；该维度不适用时填 `null`。
- 每个维度必须写一句理由，引用回答中的具体句子或给定上下文事实。
- 只根据回答全文和给定上下文评分；不要根据用例编号、来源说明或自动校验结果倒推。
- 本表不展示自动 `numericConflict` 信号；来源是否真的支持事实，由评分者判断。

## 评分维度

- `factual_correctness`：0 = 核心事实错误或编造；1 = 部分正确但有遗漏/过度概括；2 = 在给定上下文范围内事实正确
- `source_attribution`：0 = 把事实归给不支持的来源，或给出不存在的引用；1 = 有拆分但仍有一句混合多来源；2 = 每个事实都归到支持它的来源，或明确说明来源未覆盖
- `knowledge_state_honesty`：0 = 把「检索成功但预算未注入」说成「没有检索到」，或把资料没写的内容说成资料结论；1 = 表述含糊；2 = 准确区分检索成功/无匹配/预算未注入
- `task_completion`：0 = 没有回答问题；1 = 只回答一部分或没有说明缺口；2 = 回答所有可回答部分，并明确说明无法回答的部分
